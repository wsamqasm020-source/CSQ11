# 🎓 نظام تسجيل الحضور بالـ QR - موقع موحد

نظام شامل لتسجيل الحضور باستخدام تقنية QR Code مع بوابتين منفصلتين للمدرس والطالب.

## ✨ المزايا الرئيسية

### 👨‍🏫 بوابة المدرس
- ✅ إدارة كاملة للطلاب والمواد
- ✅ توليد QR Code للطلاب
- ✅ مسح الحضور بالكاميرا
- ✅ عرض التقارير والإحصائيات
- ✅ إدارة الدرجات
- ✅ إدارة المستخدمين

### 👨‍🎓 بوابة الطالب
- ✅ عرض باركود الحضور الشخصي
- ✅ سجل الحضور الكامل
- ✅ إحصائيات الحضور لكل مادة
- ✅ نسبة الحضور
- ✅ عرض الدرجات (بكود وصول)

## 🚀 التشغيل

### المتطلبات
```bash
Python 3.8+
Flask 3.0.0
```

### التثبيت
```bash
# تثبيت المكتبات
pip install -r requirements.txt

# تشغيل الموقع
python app.py
```

### الوصول للموقع
```
http://127.0.0.1:5000/
```

## 🔐 بيانات الدخول الافتراضية

### بوابة المدرس
- **المستخدم:** admin
- **كلمة المرور:** admin123

### بوابة الطالب
- **الرقم الجامعي:** يتم إدخاله من قبل المدرس

## 🌐 الاستضافة

النظام جاهز للرفع على:
- Railway
- Heroku
- PythonAnywhere
- أي استضافة تدعم Python/Flask

### إعدادات PostgreSQL
النظام يكتشف تلقائياً وجود `DATABASE_URL` ويستخدم PostgreSQL، وإلا يستخدم SQLite محلياً.

## 🔄 Routes الرئيسية

```
/ ..................... صفحة اختيار البوابة
/teacher/login ........ تسجيل دخول المدرس
/teacher/logout ....... خروج المدرس
/student/login ........ تسجيل دخول الطالب
/student/logout ....... خروج الطالب
/student/dashboard .... لوحة تحكم الطالب
/index ................ لوحة تحكم المدرس
/scanner .............. مسح الحضور
/students ............. قائمة الطلاب
/subjects ............. قائمة المواد
/attendance ........... سجل الحضور
/settings ............. الإعدادات
```

## 📱 العمل بدون إنترنت (PWA)

- ✅ Service Worker مفعّل
- ✅ يعمل بدون إنترنت
- ✅ يخزن البيانات محلياً (IndexedDB)
- ✅ مزامنة تلقائية عند عودة الاتصال

## 🛠️ التقنيات المستخدمة

- **Backend:** Python, Flask
- **Database:** SQLite (محلي), PostgreSQL (استضافة)
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **QR Code:** qrcode, html5-qrcode
- **PWA:** Service Worker, IndexedDB
