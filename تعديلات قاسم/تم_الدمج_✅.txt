✅ 1. صفحة دخول موحدة جديدة
   📄 templates/unified_login.html
   🔗 الرابط: http://127.0.0.1:5000/
   
   • صفحة اختيار بين بوابة المدرس وبوابة الطالب
   • تصميم عصري وجذاب
   • سهلة الاستخدام

✅ 2. بوابة المدرس (محدثة)
   🔗 الرابط: http://127.0.0.1:5000/teacher/login
   
   • كل المزايا الأصلية موجودة
   • إدارة الطلاب والمواد
   • مسح الحضور
   • تسجيل الدخول: admin / admin123

✅ 3. بوابة الطالب (جديدة)
   🔗 الرابط: http://127.0.0.1:5000/student/login
   📄 templates/student_login.html
   📄 templates/student_dashboard.html
   
   • تسجيل دخول بالرقم الجامعي
   • عرض باركود الحضور
   • سجل الحضور الكامل
   • إحصائيات مفصلة
   • نسبة الحضور

✅ 4. Routes جديدة
   • / → صفحة اختيار البوابة
   • /teacher/login → تسجيل دخول المدرس
   • /teacher/logout → خروج المدرس
   • /student/login → تسجيل دخول الطالب
   • /student/logout → خروج الطالب
   • /student/dashboard → لوحة تحكم الطالب
   • /student/qr-image → QR الطالب
   • /logout → خروج ذكي (يكتشف نوع المستخدم)
